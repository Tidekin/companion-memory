# 公开材料与脱敏

本次发布采用显式白名单：选定主仓库源码、项目编写的合成题库、结构化结果、
盲评票据/复核/覆盖记录、分析、报告和测试脚本。六轮原始本地材料保持原样。

题库中的人物、城市、项目、号码和隐私边界均是人工编写的虚构测试设定，
保留它们才能复现来源归属和记忆边界。发布素材来自文字渲染和通用系统 TTS，
不含私人声音克隆、真实聊天导出、字体或模型文件。

本地绝对路径和运维网络地址替换为 `LOCAL_PATH` 和文档保留地址；疑似真实
供应商令牌替换为 `REDACTED_CREDENTIAL`，出现私钥则中止导出。
数据库、缓存、密钥配置、原始供应商请求/响应日志和运维监控交接文件不在白名单内。
JSON 结构保持有效，公开脚本还进行语法检查。合成题库的输入、题目、判据及素材
在导出时单独核对，保持测试语义；各文件改动计数见 `PUBLICATION.json`。

`PUBLICATION.json` 中的 `source_sha256` 绑定原件，`public_sha256` 绑定公开副本。
历史 `freeze`、`manifest` 和验证回执仍表达当时原件的身份，可能引用未公开的运行产物；
验证本次公开文件请使用新的公开清单和 `provenance/release.json`。
公开清单不替代原始评测证据，也不把脱敏副本标为未经改动的原件。

v2 历史报告引用的 `coverage-and-freeze.json` 未在保有目录中找到。
公开报告该链接改为本次 `PUBLICATION.json`，原始缺失情况记入公开清单；
未补造历史核对记录。其余报告静态本地链接均随材料提供。

`scripts/verify_release.py` 检查哈希、题数、得分一致性、源码生成和常见敏感信息模式。
它是本次脱敏审查的辅助工具；维护者还需核对素材和代码来源。
导出脚本用于从保有原始证据的本地目录更新公开副本，不会发起模型请求。
