# 实现提示词

以下是为公开复用整理的实现任务说明。原生运行时提示词另见
`extract_rules.txt`、`review_rules.txt`、`recall_rules.txt`。
实现时请同时提供当前源码快照和架构文档作为上下文。

```text
请参考 Companion Core 的已固定记忆源码，为目标 AI 项目实现可审计的记忆流程。
先检查宿主现有的事件、权限、数据库事务、模型执行、预算和删除机制，优先复用。
先列出与参考实现的实际边界差异；缺少新协议时说明理由、替代方案和最小范围，讨论后实现。

输入：原始事件、说话者、时间、主人授权范围、已验证引用，以及模型调用结算凭据。
输出：来源绑定的事实、摘要、冲突/更正历史，以及带来源的检索上下文。

要求：
1. 提取与原文复核分开；所有结果经过严格 schema 和原文片段校验。
2. 区分主人、第三方、助手和文档；转述人的身份和事件主体分别保存。
3. 更正授权、候选 update 和正文含义一致才写替代关系；普通矛盾保留并列冲突。
4. same/conflicts/replaces 只指向合法同主体同来源类型对象，拒绝未来和未知引用。
5. 保存提取—复核检查点和失败批次。反馈修正与显式恢复有界，结算请求可复用。
6. UNKNOWN 不自动重放；预留、结算、幂等和审计由宿主持久事务承担。
7. 删除来源要覆盖记忆、引用、检查点、投影和回放，不能从旧候选复活事实。
8. 检索采用现有词法/语义通道、融合和重排；上下文保留证据、权限与硬长度限制。
9. 模型适配器只执行模型请求；存储、权限、预算和消息投递留在宿主层。
10. 用合成数据验证漏存、来源错配、更正漏标、正文越权、引用异常、失败恢复、
    UNKNOWN、并发提交及删除回放。先验证真实入口与独立工作进程，再做获准的在线验收。

交付：实现及迁移、宿主调用点、源码阅读地图、可运行示例、针对性检查结果。
保留原始评测题库/答案/判据的版本；看到评测答案后进行的修复另行记录，不能沿用旧分数
作为新实现的实测成绩。预算和全量评测次数必须事先获得明确授权。
```
