# 六轮合成记忆评测

每轮目录包含题库输入、问题、只供评审使用的判据、图片/文件/语音素材，
结构化答案与得分、评分与复核记录、报告和当轮脚本。
共同工具位于 [`benchmarks/memory_campaign`](../benchmarks/memory_campaign)。
模型答案不能读取 `review-only` 判据；在线复现要遵守原有输入隔离和预算机制。

| 轮次 | 语义题数 | 代码/判分身份与注意事项 |
| --- | ---: | --- |
| [v1](v1/) | 696 | 最早原生与参考比较；另有 18 项生命周期检查，二者分别报告 |
| [v2](v2/) | 576 | 保留新实现执行失败和 RAG 失败，未从分母中删去 |
| [v3](v3/) | 480 | 包含后续判分版本；顶层 results/summary 是当轮最终交付口径 |
| [v4](v4/) | 480 | 同轮源码固定与多票盲评；保留原有执行失败 |
| [v5](v5/) | 744 | 四臂，含闭卷对照、精确判据和事后敏感性分析 |
| [v6](v6/) | 792 | 四臂，含分组配对分析、复核修订和评测后修复说明 |

这六轮共有 3,768 个语义题实例。重复延迟、同人物和同故事的问题相关，
不能将所有题当成独立样本。各轮题目和源码不同，跨轮数字不能直接作为提升率。
题库为项目合成，自动评审与项目内复核不是独立人工评测；
题目编写、评分修订、语义边界和闭卷可猜中的影响均应连同分数阅读。

v6 新实现 `7074838d` 为 738/792，旧实现 721/792，RAG 748/792，闭卷 28/792。
分组置信区间及题库有效性敏感性见当轮分析；没有证据可把这组成绩描述为当前
快照胜过 RAG 或已通过真实长期聊天验收。
[`post-evaluation-amendment.md`](v6/post-evaluation-amendment.md)
及原生回归用例说明了评分冻结后的修复。当前快照后续修复没有重新跑全量模型评测。

## 离线核查

```sh
python scripts/verify_release.py
```

检查逐文件公开哈希、问题和答案数量、每臂通过数与最终 summary 的一致性，
不会重打分、改变判据或调用模型。原始自动评分票据、覆盖和复核记录作为
历史证据保留；离线检查不声称重新证明自动评审的语义正确性。

## 在线复现与历史脚本

完整在线原生流程需要各轮固定的 Companion Core、依赖、嵌入/重排模型、
解析服务和供应商配置。当前快照对应最新修复，用它重跑旧题将是新的实验。
`PUBLICATION.json` 记录当轮的源码身份，公共工具 README 记录正常执行步骤。
各轮保存自己的脚本与已知评分版本；有本地路径的地方已替换为 `LOCAL_PATH`，
请先改为自己的目录和环境变量，切勿把历史失败恢复脚本当作通用重放入口。

最早一轮的 `run_public_memory.py` 还通过 `upstream/demo/read_exam.py` 加载早期
公开示例作冒烟检查。该方法论仓库须由使用者自行按固定版本获取；本发布包只收录
本项目编写的脚本与合成题库，对应第三方实现继续使用其原许可。

题库生成脚本中的字体路径需改为可用中文字体；语音可用共享 PowerShell TTS 脚本
生成。这里同时提供原合成素材，离线核查无需重新生成媒体。
在线执行会产生费用，应自行明确预算、允许执行的轮次和一次性调用规则；
本次发布只进行离线核查，没有新增付费测试。

每轮公开副本的哈希与脱敏计数见 `PUBLICATION.json`。
历史清单中的原件哈希保持其证据含义，公开字节以新清单为准。
